INTRODUCTION                                           *goda-term-introduction*

goda-term.vim is the successor of ddt.vim on goda.vim: the UIs are Go, in a
binary built from your configuration (main.go), and Vim talks to it through
goda.vim.  There is no Deno.

==============================================================================
INSTALL                                                     *goda-term-install*

It needs Vim 9.1 or Neovim 0.10, Go 1.26 and goda.vim:

https://github.com/Shougo/goda.vim

==============================================================================
CONFIGURATION                                         *goda-term-configuration*

The configuration is a Go module in |g:goda_term#config_dir|: a main.go that
adds the UIs and patches the options (examples/config has one):
>go
	b := term.New()
	b.AddUI(terminal.New())
	b.PatchGlobal(term.Options{
		UIParams: map[string]term.Params{
			"terminal": {"command": []string{"zsh"}},
		},
	})
	b.Main()
<
Build it with |goda_term#build()|.

g:goda_term#config_dir                                 *g:goda_term#config_dir*
		The configuration module.
		Default: "~/.vim/goda-term", Neovim: stdpath('config') .
		'/goda-term'

g:goda_term#binary                                         *g:goda_term#binary*
		The binary built from it.
		Default: "goda-term" in the "goda-term" directory of the cache
		directory (Neovim: stdpath('cache'); Vim: $XDG_CACHE_HOME/vim
		or ~/.cache/vim, %LOCALAPPDATA%/vim on MS-Windows).

OPTIONS                                                     *goda-term-options*

Those of main.go (term.Options; Builder.PatchGlobal() and PatchLocal()),
of |goda_term#custom#patch_global()| and |goda_term#custom#patch_local()|,
and of |goda_term#start()|, merged in that order.  The params of a UI are
merged param by param.

name			(string)
		The session: a start with the name of a session shows it
		again.
		Default: "default"

ui			(string)
		The UI: "terminal", ...

uiParams		(dict)
		The params of each UI, by its name.

nvimServer		(string)
		Not used yet (as in ddt.vim).

FUNCTIONS                                                 *goda-term-functions*

goda_term#build()                                           *goda_term#build()*
		Build the configuration: "go mod tidy" and "go build".  The
		binary runs from the next request.

goda_term#start([{options}])                                *goda_term#start()*
		Show the session of {options}: a new one, or the one of the
		name again.

goda_term#ui_action({name}, {action} [, {params}])      *goda_term#ui_action()*
		Run the UI action {action} of the session {name}.

goda_term#get_input({name})                             *goda_term#get_input()*
		The command line being typed in the session {name}.

goda_term#sessions()                                     *goda_term#sessions()*
		The names of the sessions.

goda_term#ui#do_action({action} [, {params} [, {name}]])
                                                     *goda_term#ui#do_action()*
		|goda_term#ui_action()| of the session of the current buffer
		(or {name}).

goda_term#ui#get_input([{name}])                     *goda_term#ui#get_input()*
		|goda_term#get_input()| of the session of the current buffer.

goda_term#ui#kill_editor()                         *goda_term#ui#kill_editor()*
		Delete the current buffer forcibly, close the current tab, and
		go back to the window of the last UI: for the editor that
		$EDITOR started in a session ("git commit", say).
		NOTE: Unsaved changes in the buffer are lost.

goda_term#custom#patch_global({dict})        *goda_term#custom#patch_global()*
goda_term#custom#patch_global({key}, {value})
goda_term#custom#patch_local({name}, {dict})  *goda_term#custom#patch_local()*
goda_term#custom#patch_local({name}, {key}, {value})
goda_term#custom#set_global({dict})            *goda_term#custom#set_global()*
goda_term#custom#set_local({name}, {dict})      *goda_term#custom#set_local()*
		Patch (or set) the options at run time.

goda_term#custom#get_global()                  *goda_term#custom#get_global()*
goda_term#custom#get_local()                    *goda_term#custom#get_local()*
		Those patches.

goda_term#custom#get_current([{name}])        *goda_term#custom#get_current()*
		The options of the session {name} (default: that of the
		current buffer).

UI SHELL                                                   *goda-term-ui-shell*

A buffer with a prompt: each command line runs in a pseudo terminal of its
own (pipes on MS-Windows: no colors, and no terminal for a command that asks
for one), and its output, with its ANSI colors, is written in the buffer.
Its 'filetype' is "goda-term-shell".

The command line is not given to a shell: it is words with quotes and
backslashes, leading NAME=value assignments, $VAR and ${VAR}, ~ and globs;
no pipes, no redirections.  A directory alone ("../", "./sub", "/tmp") is
"cd" to it.  The builtins:

cd [{dir}]	Change the directory ($HOME without one, "-" the previous one):
		that of Vim too (|chdir()|, |DirChanged|).
history		Print the history.
time {command}	Run {command}, and print how long it took.
vim {file}	Edit {file}.
with [{word}...]
		Start the next command lines with {word}s (none: no more).

The output is that of a line printer: a line overwritten by "\r" and some
escape sequences (a progress bar) is overwritten; the other escape sequences
are dropped.  Full-screen programs are for |goda-term-ui-terminal|.

PARAMS                                              *goda-term-ui-shell-params*

aliases			(dict)
		Replace the first word of a command line: {"ls": "ls --color"}.

ansiColorHighlights	(dict)
		The highlights of the output: "fgs" and "bgs" (16 highlight
		groups of the ANSI colors), "bold", "italic", "underline".

cwd			(string)
		The directory.
		Default: the current directory

exprParams		(string[])
		The params whose strings are Vim expressions (of uiParams, the
		params as given).
		Default: ["winCol", "winRow", "winHeight", "winWidth"]

floatingBorder		(string | list)
		The border of a floating window (Neovim).

flushIntervalMs		(number)
		How often the output is written.
		Default: 100

noSaveHistoryCommands	(string[])
		Commands not written in the history.

passwordPattern		(string)
		When the output matches it (a Go regexp), a password is asked
		(|inputsecret()|).

prompt			(string)
		Default: "%"

promptHighlight		(string)
		Default: "Identifier"

promptPattern		(string)
		The prompt, a Vim regexp.
		Default: "% "

shellHistoryMax		(number)
		Default: 500

shellHistoryPath	(string)
		The history file.

split			(string)
		As |goda-term-ui-terminal-params|.

startInsert		(boolean)
		Start in Insert mode.

userPrompt		(string)
		A Vim expression shown above the prompt (lines by "\n").

userPromptHighlight	(string)
		Default: "Special"

userPromptPattern	(string)
		The lines of the user prompt, a Vim regexp.
		Default: "| .*"

winCol, winHeight, winRow, winWidth	(number | string)
		The size and the place of the window: numbers or expressions
		(|exprParams|).

ACTIONS                                            *goda-term-ui-shell-actions*

cd		{directory}: the shell goes there.
executeLine	Execute the command line of the cursor (that of another
		prompt: in a new prompt).  Typed in the command running, if
		any.
insert		{str}: typed in the command running, or in a new prompt.
nextPrompt	The cursor goes to the next prompt.
pastePrompt	The command line of the cursor, in a new prompt.
previousPrompt	The cursor goes to the previous prompt.
pushBufferStack	The command line is put aside: it comes back in the prompt
		after the next command.
redraw		Redraw the prompt.
send		{str}: executed.
setCommandLine	{str}: the command line of a new prompt.
terminate	End the command running.

UI TERMINAL                                             *goda-term-ui-terminal*

A terminal job of Vim or Neovim.  Its buffer has the 'filetype'
"goda-term-terminal".

PARAMS                                           *goda-term-ui-terminal-params*

command			(string[])
		The job.  Required.

cwd			(string)
		Its directory.
		Default: the current directory

extraTermOptions	(dict)
		More options of |term_start()| (Vim) or |jobstart()| (Neovim).

floatingBorder		(string | list)
		The border of a floating window (Neovim).

promptPattern		(string)
		The prompt of the job, a regexp: executeLine, nextPrompt,
		pastePrompt, previousPrompt and the input need it.

split			(string)
		"" (the current window), "horizontal", "vertical", "farleft",
		"farright" or "floating" (Neovim).

startInsert		(boolean)
		Enter Terminal-Job mode (Neovim; Vim always does).

winCol, winHeight, winRow, winWidth	(number)
		The size and the place of the window (50, 15, 20, 80).

ACTIONS                                         *goda-term-ui-terminal-actions*

cd		{directory}: the job goes there.
executeLine	The command line of the cursor, executed again.
insert		{str}: typed in the job.
nextPrompt	The cursor goes to the next prompt.
pastePrompt	The command line of the cursor, typed in the job.
previousPrompt	The cursor goes to the previous prompt.
redraw		Redraw the terminal.
send		{str}: typed in the job, and executed.
setCommandLine	{str}: typed in the job.

GODA-FI SOURCES                                             *goda-term-goda-fi*

The packages .../ext/fi/termtab and .../ext/fi/shellhistory are sources of
goda-fi.vim (https://github.com/Shougo/goda-fi.vim), as the ddu sources of
ddt.vim; add them in the configuration of goda-fi.vim:
>go
	import (
		"github.com/Shougo/goda-term.vim/ext/fi/shellhistory"
		"github.com/Shougo/goda-term.vim/ext/fi/termtab"
	)

	b.AddSource(termtab.NewSource())
	b.AddKind(termtab.NewKind())
	b.AddSource(shellhistory.New(shellhistory.Params{
		Paths: []string{"~/.cache/ddt-shell-history"},
	}))
	b.PatchGlobal(fi.Options{
		KindOptions: map[string]fi.KindOptions{
			"term_tab": {DefaultAction: "switch"},
		},
		SourceOptions: map[string]fi.SourceOptions{
			"term_shell_history": {DefaultAction: "execute"},
		},
	})
<
term_tab                                         *goda-term-goda-fi-term_tab*
		The tab pages, with the directory of their last UI
		(|t:goda_term_ui_last_directory|).  The kind term_tab has the
		actions:

		delete	Close the tab pages.
		edit	Change the directory of the tab page and of its UI.
		new	A new tab page, in a directory asked for.
		switch	Go to the tab page.

term_shell_history                     *goda-term-goda-fi-term_shell_history*
		The command lines of history files, the newest first.  The
		actions are for the session of the current buffer:

		edit	Edit the command line, and execute it.
		execute	Execute it.
		insert	Insert it.

		params:
		limit	(number)
			How many command lines of each file.
			Default: 500
		paths	(string[])
			The history files (expanded; those that are not
			there are skipped).  zsh's extended history too.

For example:
>vim
	nnoremap <C-t> <Cmd>call goda_fi#start(#{
	      \   name: 'term', sync: v:true,
	      \   sources: ['term_tab'],
	      \ })<CR>
	" In the buffer of a UI.
	nnoremap <buffer> <C-h> <Cmd>call goda_fi#start(#{
	      \   name: 'term', sync: v:true,
	      \   input: goda_term#ui#get_input(),
	      \   sources: ['term_shell_history'],
	      \ })<CR>
<

DIFFERENCES FROM DDT                                            *goda-term-ddt*

- The configuration is Go (main.go), not ddt.ts: ddt#custom#load_config()
  is |goda_term#build()|.
- ddt#... is goda_term#... (ddt#start() is |goda_term#start()|, ...).
- The variables are b:goda_term_name, t:goda_term_ui_..._last_name, ...
  (|goda-term-variables|), and the 'filetype' of the UIs are
  "goda-term-shell" and "goda-term-terminal" (b:ddt_ui_shell_prompt is
  b:goda_term_ui_shell_prompt).
- The UI shell keeps the blank lines of the output, and the messages are
  "goda-term: exit 1", ...
- setCommandLine only: no setPrompt.
- The ddu sources ddt_tab and ddt_shell_history are the goda-fi sources
  term_tab and term_shell_history (|goda-term-goda-fi|).
